🏅 Olympics Data Analysis Dashboard

An interactive Olympic Games analytics dashboard covering 120 years of Olympic history (1896–2016) — medal tallies, country and athlete performance, sport, gender and age breakdowns, and historical records.

This project is built with Streamlit, which runs as a live Python server. Netlify only serves static sites and serverless functions, so it can't run Streamlit directly — that's why this page is a placeholder instead of the live dashboard.

To run the dashboard yourself:

  • Clone the repository
  • pip install -r requirements.txt
  • streamlit run app.py

To make it publicly reachable on the web, deploy it on a host that runs persistent Python processes, such as Streamlit Community Cloud, Render, or Railway.
