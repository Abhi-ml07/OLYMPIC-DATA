# 🏅 Olympics Data Analysis Dashboard

An interactive **Olympic Games Analytics Dashboard** built with **Python** and **Streamlit** using the **120 Years of Olympic History (1896–2016)** dataset.

## 📌 Features

* 📊 Overall Olympic Statistics
* 🥇 Medal Tally Analysis
* 🌍 Country-wise Performance
* 🏃 Athlete Statistics
* 🏆 Sport-wise Analysis
* 👨‍👩‍👧 Gender Participation Analysis
* 🎂 Age Distribution Analysis
* 📅 Olympic Timeline
* ⭐ Olympic Records
* 📈 Interactive Charts & Filters

## 🛠️ Tech Stack

* Python
* Streamlit
* Pandas
* NumPy
* Plotly
* Matplotlib
* Seaborn
* Scikit-learn (Optional)

## 📂 Dataset

* **120 Years of Olympic History (1896–2016)**
* `athlete_events.csv`
* `noc_regions.csv`

## 🚀 Installation

```bash
git clone <repository-url>
cd Olympics-Data-Analysis

python -m venv venv

# Windows
venv\Scripts\activate

pip install -r requirements.txt

streamlit run app.py
```
