🏅 Olympics Data Analysis Dashboard

This repository contains a Streamlit dashboard for exploring 120 years of Olympic history (1896–2016) — medal tallies, country and athlete performance, sport-level stats, gender and age analysis, and more.

Streamlit apps run as a persistent Python server, which Netlify does not host (Netlify serves static sites and serverless functions). To run this dashboard, use it locally or deploy it to a Python-friendly host such as Streamlit Community Cloud, Render, or Railway.

Run locally

pip install -r requirements.txt
streamlit run app.py

See the project README for full details on features and project structure.
